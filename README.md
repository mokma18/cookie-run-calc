# 🍪 쿠키런 크럼블 - 장비 스탯 & 종결도 비교 분석기

쿠키런 크럼블 인게임 장비 팝업 스크린샷을 등록하거나 수치를 직접 입력하여, **[기존 장비(장착중)]**와 **[신규 획득 장비]**의 메인 스탯 및 보조옵션 2개의 종결도(%)를 실시간으로 비교·분석하는 웹 애플리케이션입니다.

외부 백엔드 서버 없이 단일 HTML 파일(`index.html`)과 브라우저 클라이언트 사이드 OCR(`Tesseract.js`)로 구동되므로 **GitHub Pages**에 올리는 즉시 무료로 웹 호스팅하여 모바일/PC 어디서나 사용할 수 있습니다.

---

## 🚀 주요 기능
1. **듀얼 장비 1:1 비교 UI**
   - 좌측: 🛡️ 기존 장착 장비
   - 우측: ✨ 신규 획득 장비
2. **스크린샷 자동 OCR 인식**
   - 모바일 갤러리 이미지 선택 및 PC 화면 어디서나 캡처 후 붙여넣기(`Ctrl + V`) 지원
   - 2개 장비가 함께 표시된 화면의 좌/우 영역을 자동 분할하여 레벨, 등급(이터널/레전더리), 강화 수치(+0~+20), 메인/보조옵션 스탯명 및 수치 자동 추출
3. **강화 단계별 종결도(%) 실시간 계산**
   - 강화 배율(`+0~+4: x1.0`, `+5~+9: x1.3`, `+10~+14: x1.7`, `+15~+19: x2.3`, `+20: x3.0`) 자동 적용
   - 이론상 최소~최대치 기준 실시간 달성률(%) 및 프로그레스 바(녹색/주황색/적색) 시각화
4. **수동 입력 및 즉각 수정 지원**
   - OCR 미인식 또는 수치 수정이 필요한 경우 드롭다운과 입력창으로 실시간 재계산

## 🌐 GitHub Pages로 1분 만에 웹 배포하기

1. **GitHub 저장소(Repository) 생성**
   - GitHub 로그인 후 우측 상단 `+` 버튼 -> **New repository** 클릭
   - Repository name 입력 (예: `cookie-run-calc`)
   - **Public** 선택 후 **Create repository** 클릭
2. **파일 업로드**
   - 저장소 메인 화면에서 **uploading an existing file** 클릭
   - `index.html`과 `README.md` 파일을 드래그하여 업로드하고 **Commit changes** 클릭
3. **GitHub Pages 활성화**
   - 저장소 상단 탭에서 **Settings** -> 좌측 메뉴에서 **Pages** 클릭
   - **Build and deployment** 항목의 Branch를 `None`에서 `main`(또는 `master`)으로 변경하고 폴더는 `/ (root)` 선택 후 **Save** 클릭
4. **접속 확인**
   - 약 30초~1분 후 상단에 생성된 웹사이트 주소(예: `https://<당신의GitHub아이디>.github.io/cookie-run-calc/`)로 스마트폰이나 PC에서 접속 가능!

## 🛠️ 코드 수정 및 커스텀 가이드 (`index.html`)

모든 로직과 스타일은 `index.html` 단일 파일 내에 깔끔하게 모듈화되어 있습니다. 필요에 따라 아래 위치를 수정하시면 됩니다.

### 1. 보조옵션 최소/최대치 범위 수정 (`SUB_RANGES`)
스크립트 상단의 `SUB_RANGES` 객체에서 등급별 0강 기준 이론치 범위를 수정할 수 있습니다:
```javascript
const SUB_RANGES = {
  "공격력":   { "레전더리": [131, 164],     "이터널": [266, 335] },
  "방어력":   { "레전더리": [131, 164],     "이터널": [266, 335] },
  "체력":     { "레전더리": [1849, 2315],   "이터널": [3755, 4701] },
  "명중":     { "레전더리": [33, 67],       "이터널": [40, 79] },
  "치명확률": { "레전더리": [4.0, 8.0],     "이터널": [4.8, 9.6] },
  "치명피해": { "레전더리": [2.9, 5.8],     "이터널": [3.6, 7.2] },
  "스킬증폭": { "레전더리": [2.4, 3.2],     "이터널": [3.2, 4.0] },
  "치명저항": { "레전더리": [4.0, 8.0],     "이터널": [4.8, 9.6] },
  "피해감소": { "레전더리": [1.8, 2.4],     "이터널": [2.4, 3.0] },
  "집중":     { "레전더리": [42, 83],       "이터널": [50, 98] },
  "스킬가속": { "레전더리": [2, 2],         "이터널": [2, 2] }
};
```

### 2. 강화 단계별 배율 공식 (`getSubMultiplier`)
강화 구간에 따른 보조옵션 증가 배율을 수정할 때:
```javascript
function getSubMultiplier(enh) {
  if (enh >= 20) return 3.0;
  if (enh >= 15) return 2.3;
  if (enh >= 10) return 1.7;
  if (enh >= 5)  return 1.3;
  return 1.0;
}
```

### 3. OCR 텍스트 인식 정규표현식 매핑 (`STATS_MAP`)
인게임 폰트나 줄임말, 오타 교정을 위한 정규표현식 추가:
```javascript
const STATS_MAP = {
  "스킬증폭": /(?:스킬증폭|스킬중폭|증폭)/i,
  "스킬가속": /(?:스킬가속|가속)/i,
  "치명확률": /(?:치명확률|치명확|치확)/i,
  ...
};
```

### 4. 종결도 계산 및 평가 로직 (`evalStat`)
최소치~최대치 사이 달성도(%) 산출 공식 및 점수별 색상 분기:
```javascript
let pct = ((val - min) / (max - min)) * 100;
let pClass = pct >= 75 ? "p-high" : (pct >= 40 ? "p-mid" : "p-low");
```
